## 🚀 Featured Projects

### 🖱️ AutoClick AC

A free, lightweight, and open-source autoclicker for Windows.

**Features:**
- Five adjustable clicking speed levels
- Left and right mouse button support
- Global F6 start/stop shortcut
- Keyboard speed controls
- Windows system tray support
- Custom dark interface

**[View Project](https://github.com/JakkByte/AutoClick-AC)** · **[Download for Windows](https://github.com/JakkByte/AutoClick-AC/releases/latest)**

### 🎵 Video to MP3

A free, lightweight, and open-source video-to-MP3 converter for Windows.

**Features:**
- Convert video files into MP3 audio
- Batch conversion of multiple videos
- Support for MP4, MKV, AVI, MOV, WEBM, and more
- Five available languages
- Background conversion with progress tracking
- Prevents overwriting existing MP3 files
- Modern dark interface
- No Python installation required

**[View Project](https://github.com/JakkByte/Video-to-MP3)** · **[Download for Windows](https://github.com/JakkByte/Video-to-MP3/releases/latest)**
