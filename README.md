## 🚀 Featured Project

### 🖱️ AutoClick AC

A free, lightweight, and open-source autoclicker for Windows.

**Features:**
- Five adjustable clicking speed levels
- Left and right mouse button support
- Global F6 start/stop shortcut
- Keyboard speed controls
- Windows system tray support
- Custom dark interface
